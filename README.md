# VLSI Design Internship - Task 2

## Introduction

This repository contains the implementation of basic combinational circuits using Verilog HDL as part of the VLSI Design Internship Task-2.

## Circuits Implemented

- AND Gate
- OR Gate
- NOT Gate
- NAND Gate
- NOR Gate
- XOR Gate
- Half Adder
- Full Adder

## Tools Used

- Verilog HDL
- Xilinx Vivado
- Vivado Simulator

## Repository Structure

- Design_Files – Verilog design modules
- Testbench – Testbench files
- Waveforms – Simulation results
- RTL_Schematics – RTL diagrams
- Report.pdf – Internship report

## Learning Outcomes

- Verilog HDL fundamentals
- RTL design
- Combinational logic design
- Testbench creation
- Simulation and waveform analysis
